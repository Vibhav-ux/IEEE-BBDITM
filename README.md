# IEEE BBDITM Webpage

Official website for the **IEEE Student Branch – BBDITM Lucknow**.

## Features

* Responsive modern UI
* Events section
* Team members section
* Gallery page
* Contact page
* Supabase integration

## Tech Stack

* React
* TypeScript
* Vite
* Tailwind CSS
* Supabase

## Run Locally

```bash
npm install
npm run dev
```
